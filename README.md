# 🔐 Maskr - AI Image Steganography

Maskr is an image steganography project that allows users to hide secret messages inside images and decode them later.

## 🚀 Features

- Hide secret messages inside images
- Decode hidden messages
- LSB-based image steganography
- Randomized message placement
- SHA-256 seed generation
- ResNet50 image feature extraction
- Flutter frontend
- Python Flask backend

## 🛠️ Technologies Used

- Flutter & Dart
- Python
- Flask
- TensorFlow
- ResNet50
- Pillow
- NumPy
